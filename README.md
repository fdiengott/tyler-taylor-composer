# Tyler Taylor Composer Portfolio

This is a site I made for a dear friend who is a professional composer and musician. I tried to keep it really simple and very easy to maintain since I figure I will be the one maintaining it for the foreseeable future.

It is, for the most part, a static site made with Astro and React (with a few javascript islands with iframes for Facebook, Youtube, and SoundCloud). The initial template was the Dante Theme by justgoodui.com.

[Here is the link to the live site](https://tylertaylorcomposer.com/).
